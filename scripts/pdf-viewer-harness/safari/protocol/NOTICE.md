# WebKit protocol definitions

Runtime.json, Network.json, Memory.json and CPUProfiler.json come from the
WebKit JavaScriptCore inspector protocol directory. The files retain the
upstream definitions; JSON indentation is normalized where recorded in
provenance.json. That file records the exact upstream revision and URLs,
the source comparison date, and both local and upstream byte hashes.

The upstream protocol JSON files contain no inline copyright or license
headers. COPYING.LIB reproduces the JavaScriptCore component license from
the same revision. WebKit's licensing policy is available at
https://webkit.org/licensing-webkit/.

These definitions describe available native protocol fields. Runtime
receipts record which events and fields the attached Safari actually
provides.
